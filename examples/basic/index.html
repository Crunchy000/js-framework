jsonx feature tour

Every feature in one page. The server sends JSON shaped for the page, and templates turn it into HTML in the browser. For a full app, see the todo app.

1. A region

This box has a <template> inside, so it's a region. Its jx-get loads the view when the page opens. The button inside it calls jx-post, and the answer redraws the region.

2. Live search

jx-trigger="input delay:300ms" waits until you stop typing, then sends ?q=.... The results go into another element with jx-target. The template uses jx-each, jx-if and class:pioneer.

    3. Web components

    a) A component that fires a custom event

    <star-rating> fires rating-changed. jsonx listens for it and POSTs the component's value.

    b) A component that receives JSON as a property

    jx-swap="prop:stats" sets todoStats.stats = data instead of drawing a template.

    c) Components that use jsonx inside their shadow DOM

    Each card has its own template and target hidden in its shadow root.
