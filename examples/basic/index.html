Regions

An element with a <template> inside is a region. It loads its view, and buttons inside it redraw it. While a request runs, the element gets the class jx-loading.

    Functions and shared data
    
    
    fn:click calls the function click(values) instead of a server. jx-data="clicks" draws the variable clicks, and after any fn: call every jx-data region is drawn again. Use a plain script, not a module, so jsonx can find them by name.
