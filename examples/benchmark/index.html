Rendering benchmark

How long it takes to draw a todo list of Web Awesome components, and to update it after ticking one todo. Each number is the median of several runs, timed from the start of the render until the browser has drawn the next frame. No network is involved.

jsonx renders the list with a jsonx template, which Lit updates in place. innerHTML is the simple approach for comparison: build the HTML as a string and replace the whole list, every time.
