Rendering benchmark

How long it takes to update a todo list after ticking one todo. Each number is the median of several runs, timed from the start of the update until the browser has drawn the next frame. No network is involved.

Five ways to update the same list:

  • jsonx: a jsonx template, which Lit updates in place.
  • React: React 18.3.1 (production build). Every update re-renders all rows, and React diffs them. Rows have keys.
  • htmx: htmx 2.0.4 swaps in HTML from the server with its default innerHTML swap. Here the server's HTML is built in the page, so no network is involved.
  • htmx + morph: the same HTML, merged into the live page by idiomorph 0.3.0, which is what htmx's morph extension does. Unchanged elements are kept.
  • innerHTML: the simple approach, with no library. Build the HTML as a string and replace the whole list, every time.

React renders with flushSync, so its work happens inside the timing, like the others. Download size, gzipped: React + ReactDOM is about 47 KB minified. htmx is about 16 KB minified, plus 3 KB for idiomorph. jsonx + lit-html is about 17 KB, unminified with all its comments.
