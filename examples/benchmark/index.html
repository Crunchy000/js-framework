Rendering benchmark

Times how long jsonx takes to show a todo list of Web Awesome components, and to update it after ticking one todo. Each number is the median of several runs, from the request starting until the browser has drawn the next frame. The fake API answers instantly, so network time isn't included.

innerHTML throws the old list away and builds a new one. morph uses idiomorph to change only what's different.
