jsonx

HTML templates and plain JavaScript. Keep your data in ordinary variables, change it with ordinary functions, and the parts of the page that use it redraw by themselves. No build step, nothing to import, and every component is a real web component.

<script>
  let count = 0;
  function up() { count++; }
</script>

<div jx:data="count">
  <template>
    <wa-button on:click="up">
      Clicked {{count}} times
    </wa-button>
    <jx-if test="count">Nice.</jx-if>
  </template>
</div>

This, running:

  • Events call functions. on:click="add", on:submit="save", on:input.delay-300="search". A function gets the values of the inputs around it.
  • Nothing to wire up. After a function runs, jsonx sees which variables changed and redraws only what uses them.
  • Components in .jx files. A template with a tag name, its own script, props, lifecycle and form fields, drawn by Lit.
